Proiect Examen - Cursa de Masini

Acesta este un program simplu realizat in C pentru examenul de programare. 

Descriere:

Programul simuleaza o cursa intre doua masini (A si B) intr-o interfata de tip consola. 
Masinile avanseaza pas cu pas pana cand ajung la linia de sosire (finish).

Cum functioneaza:

- Codul utilizeaza o bucla `while` pentru a controla desfasurarea cursei.
- Pozitiile masinilor sunt reprezentate prin variabilele `A` si `B`.
- Se foloseste biblioteca `stdio.h` pentru afisarea caracterelor pe ecran.

Tehnologii utilizate:

- Limbajul C
- Mediu de dezvoltare: Code::Blocks
